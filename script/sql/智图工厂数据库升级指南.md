# 智图工厂数据库升级指南

## 📋 概述

本指南帮助您将现有的若依AI系统数据库升级以支持智图工厂功能。升级基于现有的设计师生态管理系统，新增任务管理、申请审核、交付管理和支付功能。

## 🔍 升级前检查

### 1. 确认现有表结构

在执行升级前，请确认数据库中已存在以下基础表：

```sql
-- 检查必需的基础表
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'your_database_name' 
AND table_name IN (
    'des_designer',     -- 设计师表
    'des_enterprise',   -- 企业表  
    'des_school',       -- 院校表
    'sys_menu'          -- 系统菜单表
);
```

### 2. 数据备份

**⚠️ 重要：执行升级前请备份数据库**

```bash
# MySQL备份命令
mysqldump -u用户名 -p密码 数据库名 > backup_$(date +%Y%m%d_%H%M%S).sql
```

## 🔧 环境配置

### 1. 应用配置文件更新

在应用的配置文件中添加审核模式配置：

```yaml
# application.yml 或 application-dev.yml
zhitu:
  factory:
    review:
      mode: DUAL  # 双重审核模式（DUAL/ENTERPRISE）
    payment:
      enabled: true
    notification:
      enabled: true
```

### 2. 前端环境变量

```bash
# .env.development
VITE_TASK_REVIEW_MODE=DUAL

# .env.production  
VITE_TASK_REVIEW_MODE=ENTERPRISE
```

## ❗ 注意事项

### 1. 审核模式配置
- 生产环境建议使用 `ENTERPRISE` 模式（企业自主审核）
- 开发环境可使用 `DUAL` 模式（双重审核）进行功能测试

### 2. 数据安全
- 系统管理员审核信息对企业管理员和设计师完全透明
- 确保前端不会暴露敏感的审核字段

### 3. 性能考虑
- 为高频查询字段创建了索引
- 建议定期清理软删除的数据

### 4. 兼容性
- 升级脚本兼容MySQL 8.0+
- 使用JSON字段需要确保MySQL版本支持

## 🆘 常见问题

### Q1: 外键约束错误
**A**: 确保 `des_enterprise` 和 `des_designer` 表中存在对应的记录，或暂时禁用外键检查。

### Q2: 权限菜单未显示  
**A**: 检查角色是否正确分配了智图工厂相关权限，确认菜单状态为正常。

### Q3: JSON字段不支持
**A**: 确保MySQL版本为5.7+，或将JSON字段修改为TEXT类型。

4. 环境变量配置是否正确
