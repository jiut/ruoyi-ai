# 院校管理接口权限检查

## 概述

本文档说明了院校管理接口的权限控制机制，确保院校管理员只能访问本校数据，其他管理接口只有超级管理员可以访问。

## 权限分类

### 1. 超级管理员权限
- 拥有所有院校管理接口的完全访问权限
- 可以查看、修改、删除任意院校的数据
- 可以创建新院校和查看任意用户的院校绑定关系

### 2. 院校管理员权限
- 只能访问自己绑定院校的数据
- 可以查看和修改自己院校的信息
- 可以查看自己院校的就业统计和分布数据
- 无法创建、删除院校或访问其他院校的数据

## 接口权限详情

### GET /designer/school/list - 查询院校列表
- **超级管理员**：返回所有院校列表
- **院校管理员**：仅返回自己绑定的院校信息
- **其他用户**：返回空列表

### GET /designer/school/{schoolId} - 获取院校详情
- **超级管理员**：可以查看任意院校详情
- **院校管理员**：只能查看自己绑定的院校详情
- **其他用户**：无权访问

### POST /designer/school - 新增院校
- **仅超级管理员**：可以创建新院校
- **其他用户**：无权访问（@SaCheckRole("admin")）

### PUT /designer/school - 修改院校
- **超级管理员**：可以修改任意院校信息
- **院校管理员**：只能修改自己绑定的院校信息
- **其他用户**：无权访问

### DELETE /designer/school/{schoolIds} - 删除院校
- **仅超级管理员**：可以删除院校
- **其他用户**：无权访问（@SaCheckRole("admin")）

### GET /designer/school/user/{userId} - 根据用户ID查询院校
- **仅超级管理员**：可以查询任意用户的院校绑定
- **其他用户**：无权访问（@SaCheckRole("admin")）

### GET /designer/school/{schoolId}/employment/statistics - 获取就业统计
- **超级管理员**：可以查看任意院校的就业统计
- **院校管理员**：只能查看自己绑定院校的就业统计
- **其他用户**：无权访问

### GET /designer/school/{schoolId}/employment/distribution - 获取就业分布
- **超级管理员**：可以查看任意院校的就业分布
- **院校管理员**：只能查看自己绑定院校的就业分布
- **其他用户**：无权访问

## 技术实现

### 权限检查机制
1. **超级管理员检查**：使用 `LoginHelper.isSuperAdmin()` 方法
2. **院校绑定检查**：通过 `userBindingService.getSchoolIdByUserId(userId)` 获取用户绑定的院校ID
3. **数据范围控制**：在Service层添加 `selectSchoolListBySchoolId` 方法实现数据过滤

### 注解权限控制
- `@SaCheckPermission("designer:school:*")`：基础权限检查
- `@SaCheckRole("admin")`：仅限超级管理员访问的接口

### 业务逻辑权限控制
- 在Controller方法中添加用户角色检查
- 根据用户角色和绑定关系过滤返回数据
- 对于修改和查询操作，验证用户是否有权限操作指定院校

## 安全保障

1. **数据隔离**：院校管理员无法访问其他院校的数据
2. **操作限制**：院校管理员无法执行超出权限范围的操作
3. **权限最小化**：每个用户角色只拥有必要的最小权限集合
