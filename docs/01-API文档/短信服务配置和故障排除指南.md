# 短信服务配置和故障排除指南

## 🚨 常见错误及解决方案

### 错误1：NoSuchBeanDefinitionException

**错误信息：**
```
org.springframework.beans.factory.NoSuchBeanDefinitionException: No qualifying bean of type 'org.ruoyi.common.sms.core.SmsTemplate' available
```

**原因分析：**
`SmsTemplate` Bean 没有被正确创建，通常由以下原因导致：

1. **短信服务未启用**：配置文件中 `sms.enabled` 不为 `true`
2. **缺少SDK依赖**：运行时classpath中没有阿里云或腾讯云的SMS SDK
3. **配置不完整**：短信服务的认证信息配置错误

## 🔧 解决方案

### 方案1：完整配置短信服务（推荐）

#### 步骤1：添加依赖

确保 `ruoyi-admin/pom.xml` 中包含短信模块依赖：

```xml
<dependencies>
    <!-- 短信模块 -->
    <dependency>
        <groupId>org.ruoyi</groupId>
        <artifactId>ruoyi-common-sms</artifactId>
    </dependency>
    
    <!-- 阿里云短信SDK（二选一） -->
    <dependency>
        <groupId>com.aliyun</groupId>
        <artifactId>dysmsapi20170525</artifactId>
        <version>${aliyun.sms.version}</version>
    </dependency>
    
    <!-- 腾讯云短信SDK（二选一） -->
    <dependency>
        <groupId>com.tencentcloudapi</groupId>
        <artifactId>tencentcloud-sdk-java-sms</artifactId>
        <version>${tencent.sms.version}</version>
    </dependency>
</dependencies>
```

#### 步骤2：配置文件设置

在 `application.yml` 或 `application-dev.yml` 中配置：

**阿里云短信配置：**
```yaml
sms:
  enabled: true
  endpoint: "dysmsapi.aliyuncs.com"
  accessKeyId: "your-access-key-id"
  accessKeySecret: "your-access-key-secret"
  signName: "your-sign-name"
```

**腾讯云短信配置：**
```yaml
sms:
  enabled: true
  endpoint: "sms.tencentcloudapi.com"
  accessKeyId: "your-secret-id"
  accessKeySecret: "your-secret-key"
  signName: "your-sign-name"
  sdkAppId: "your-sdk-app-id"
```

#### 步骤3：获取短信服务凭证

**阿里云短信服务：**
1. 登录 [阿里云控制台](https://dysms.console.aliyun.com/)
2. 开通短信服务
3. 创建签名和模板
4. 获取 AccessKey ID 和 AccessKey Secret

**腾讯云短信服务：**
1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/smsv2)
2. 开通短信服务
3. 创建签名和模板
4. 获取 SecretId、SecretKey 和 SDKAppID

### 方案2：临时禁用短信验证

如果暂时不需要短信功能，可以修改配置：

```yaml
sms:
  enabled: false  # 禁用短信服务
```

### 方案3：使用Mock短信服务（开发环境）

创建Mock短信服务用于开发测试：

```java
@Configuration
@ConditionalOnProperty(value = "sms.mock.enabled", havingValue = "true")
public class MockSmsConfig {
    
    @Bean
    @Primary
    public SmsTemplate mockSmsTemplate() {
        return new SmsTemplate() {
            @Override
            public SmsResult send(String phones, String templateId, Map<String, String> param) {
                // Mock实现：仅打印日志，不实际发送短信
                log.info("Mock短信发送 - 手机号: {}, 模板: {}, 参数: {}", phones, templateId, param);
                return SmsResult.builder()
                    .isSuccess(true)
                    .message("Mock短信发送成功")
                    .response("mock-response")
                    .build();
            }
        };
    }
}
```

配置文件添加：
```yaml
sms:
  enabled: false  # 禁用真实短信服务
  mock:
    enabled: true  # 启用Mock服务
```

## 🔍 故障排除步骤

### 1. 检查配置文件

确认 `application.yml` 中短信配置正确：

```bash
# 查看当前配置
grep -A 10 "sms:" application.yml
```

### 2. 检查依赖

确认项目中包含必要的短信SDK依赖：

```bash
# 检查依赖树
mvn dependency:tree | grep -E "(sms|aliyun|tencent)"
```

### 3. 检查Bean注册

在应用启动时查看日志，确认 SmsTemplate Bean 是否被创建：

```bash
# 查看启动日志中的Bean创建信息
grep -i "smstemplate\|smsconfig" application.log
```

### 4. 测试配置

创建测试接口验证短信服务：

```java
@RestController
@RequestMapping("/test")
public class SmsTestController {
    
    @Autowired(required = false)
    private SmsTemplate smsTemplate;
    
    @GetMapping("/sms/check")
    public R<String> checkSmsService() {
        if (smsTemplate == null) {
            return R.fail("短信服务未配置或未启用");
        }
        return R.ok("短信服务配置正常");
    }
}
```

## 🛡️ 安全注意事项

### 1. 凭证安全
- 不要在代码中硬编码Access Key
- 使用环境变量或外部配置文件
- 定期轮换Access Key

### 2. 配置示例
```yaml
sms:
  enabled: true
  endpoint: "dysmsapi.aliyuncs.com"
  accessKeyId: "${SMS_ACCESS_KEY_ID}"
  accessKeySecret: "${SMS_ACCESS_KEY_SECRET}"
  signName: "${SMS_SIGN_NAME}"
```

### 3. 环境变量设置
```bash
export SMS_ACCESS_KEY_ID="your-access-key-id"
export SMS_ACCESS_KEY_SECRET="your-access-key-secret"
export SMS_SIGN_NAME="your-sign-name"
```

## 📝 常见问题FAQ

### Q: 短信发送失败，显示"签名不存在"？
A: 检查配置文件中的 `signName` 是否与短信服务控制台中的签名一致。

### Q: 短信发送失败，显示"模板不存在"？
A: 检查代码中的模板ID是否正确，确保模板已在控制台中审核通过。

### Q: 开发环境如何测试短信功能？
A: 建议使用Mock短信服务或配置测试专用的短信模板。

### Q: 如何限制短信发送频率？
A: 可以使用Redis实现发送频率限制，建议同一手机号60秒内只能发送一次。
