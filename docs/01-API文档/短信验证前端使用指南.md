# 短信验证前端使用指南

## 📋 概述

本指南详细说明前端如何集成和使用若依AI平台的短信验证功能，包括验证码发送、用户登录等核心功能。

## 🚀 功能特性

- ✅ 支持手机号验证码发送
- ✅ 4位数字验证码，5分钟有效期
- ✅ 基于短信验证码的用户登录
- ✅ 多租户隔离支持
- ✅ 完善的错误处理机制

## 📡 API接口说明

### 1. 获取短信验证码

**接口地址：** `GET /resource/sms/code`

**请求参数：**
```
phonenumber: string (必填) - 用户手机号码，需符合手机号格式
scene: string (可选) - 使用场景，支持以下值：
  - register: 注册（手机号不能已注册）
  - login: 登录（手机号必须已注册）
  - bind: 绑定（手机号不能被占用）
  - reset: 重置密码（手机号必须已注册）
  - 默认为 login
```

**请求示例：**
```javascript
// 方式1：登录场景（默认）
GET /resource/sms/code?phonenumber=13800138000

// 方式2：注册场景
GET /resource/sms/code?phonenumber=13800138000&scene=register

// 方式3：使用axios
const response = await axios.get('/resource/sms/code', {
  params: {
    phonenumber: '13800138000',
    scene: 'register'  // 可选
  }
});
```

**响应格式：**
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

**错误响应示例：**
```json
{
  "code": 500,
  "msg": "当前系统没有开启短信功能！",
  "data": null
}
```

**场景验证错误示例：**
```json
// 注册场景 - 手机号已被注册
{
  "code": 500,
  "msg": "该手机号已被注册，请直接登录或使用其他手机号",
  "data": null
}

// 登录场景 - 手机号未注册
{
  "code": 500,
  "msg": "该手机号尚未注册，请先注册或检查手机号是否正确",
  "data": null
}
```

### 2. 绑定用户手机号

**接口地址：** `POST /system/user/bind/phone`

**请求体：**
```json
{
  "phonenumber": "13800138000",
  "smsCode": "1234"
}
```

**字段说明：**
- `phonenumber`: 手机号码（11位数字，1开头）
- `smsCode`: 4位数字验证码

**请求示例：**
```javascript
const bindData = {
  phonenumber: "13800138000",
  smsCode: "1234"
};

const response = await axios.post('/system/user/bind/phone', bindData);
```

**成功响应：**
```json
{
  "code": 200,
  "msg": "手机号绑定成功",
  "data": null
}
```

**错误响应示例：**
```json
{
  "code": 500,
  "msg": "该手机号已被其他用户绑定",
  "data": null
}
```

## 🔄 完整使用流程

### 场景1：用户绑定手机号

#### 步骤1：发送验证码

```javascript
/**
 * 为绑定手机号发送验证码
 * @param {string} phoneNumber - 手机号码
 */
async function sendSmsCodeForBind(phoneNumber) {
  try {
    // 验证手机号格式
    if (!validatePhoneNumber(phoneNumber)) {
      throw new Error('请输入正确的手机号码');
    }
    
    const response = await axios.get('/resource/sms/code', {
      params: { 
        phonenumber: phoneNumber,
        scene: 'bind'  // 绑定场景
      }
    });
    
    if (response.data.code === 200) {
      // 发送成功，启动倒计时
      startCountdown();
      showMessage('验证码已发送，请查收短信');
    } else {
      throw new Error(response.data.msg);
    }
  } catch (error) {
    console.error('发送验证码失败:', error);
    showMessage(error.message || '发送失败，请重试');
  }
}
```

/**
 * 绑定手机号到当前用户

  try {
    // 验证输入

### 步骤2：实现倒计时功能

```javascript
let countdownTimer = null;
let countdownSeconds = 60;

/**
 * 启动发送按钮倒计时
 */
function startCountdown() {
  const sendButton = document.getElementById('sendSmsBtn');
  countdownSeconds = 60;
  
  sendButton.disabled = true;
  sendButton.textContent = `${countdownSeconds}s后重发`;
  
  countdownTimer = setInterval(() => {
    countdownSeconds--;
    
    if (countdownSeconds <= 0) {
      clearInterval(countdownTimer);
      sendButton.disabled = false;
      sendButton.textContent = '发送验证码';
    } else {
      sendButton.textContent = `${countdownSeconds}s后重发`;
    }
  }, 1000);
}
```

### 步骤3：短信登录

```javascript
/**
 * 短信验证码登录
 * @param {string} phoneNumber - 手机号码
 * @param {string} smsCode - 验证码
 */
async function smsLogin(phoneNumber, smsCode) {
  try {
    // 验证输入
    if (!validatePhoneNumber(phoneNumber)) {
      throw new Error('请输入正确的手机号码');
    }
    
    if (!smsCode || smsCode.length !== 4) {
      throw new Error('请输入4位验证码');
    }
    
    const loginData = {
      tenantId: "000000", // 默认租户
      phonenumber: phoneNumber,
      smsCode: smsCode
    };
    
    const response = await axios.post('/auth/smsLogin', loginData);
    
    if (response.data.code === 200) {
      // 登录成功
      const { token, userInfo } = response.data.data;
      
      // 保存token
      localStorage.setItem('access_token', token);
      
      // 保存用户信息
      localStorage.setItem('userInfo', JSON.stringify(userInfo));
      
      // 跳转到主页面
      window.location.href = '/dashboard';
      
      showMessage('登录成功');
    } else {
      throw new Error(response.data.msg);
    }
  } catch (error) {
    console.error('登录失败:', error);
    showMessage(error.message || '登录失败，请重试');
  }
}
```

## 🚨 错误码说明

| 错误码 | 错误信息 | 说明 |
|-------|---------|------|
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 手机号格式不正确或验证码格式错误 |
| 500 | 当前系统没有开启短信功能 | 后端短信服务未启用 |
| 500 | 验证码已过期 | 验证码超过5分钟有效期 |
| 500 | 验证码错误 | 输入的验证码不匹配 |
| 500 | 用户不存在 | 该手机号未注册 |
| 500 | 该手机号已被其他用户绑定 | 手机号重复绑定 |
| 500 | 验证码已过期 | 验证码超过有效期 |
| 500 | 手机号绑定失败 | 数据库更新失败 |
| 500 | 该手机号已被注册 | 注册场景下手机号已存在 |
| 500 | 该手机号尚未注册 | 登录场景下手机号不存在 |
| 500 | 手机号格式不正确 | 手机号格式验证失败 |

## 📝 注意事项

### 安全性
1. **验证码有效期**: 验证码5分钟后自动失效
2. **频率限制**: 建议前端实现60秒发送间隔限制
3. **输入验证**: 前端需验证手机号格式和验证码长度

### 用户体验
1. **倒计时显示**: 发送后显示倒计时，防止频繁点击
2. **错误提示**: 清晰的错误信息提示
3. **加载状态**: 发送和登录时显示加载状态
4. **自动清理**: 组件卸载时清理定时器

### 兼容性
1. **租户支持**: 默认使用租户ID "000000"
2. **Token管理**: 登录成功后保存token到localStorage
3. **跨域配置**: 确保API请求的跨域配置正确

## 🔧 配置要求

### 后端配置确认
确保后端 `application.yml` 中短信配置已启用：

```yaml
sms:
  enabled: true
  endpoint: "dysmsapi.aliyuncs.com"  # 或腾讯云
  accessKeyId: "your-access-key"
  accessKeySecret: "your-secret-key"
  signName: "your-sign-name"
```

### axios 拦截器配置
```javascript
// 请求拦截器 - 添加token
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器 - 统一错误处理
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // token过期，跳转登录
      localStorage.removeItem('access_token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```
