# 若依AI不同接口文件大小限制实施指南

## 🎯 功能概述

为项目实现了灵活的文件大小限制系统，支持：
- ✅ **注解式配置** - 通过@FileSizeLimit注解轻松设置
- ✅ **自动类型识别** - 根据文件类型智能选择限制
- ✅ **接口级别控制** - 每个接口可独立设置限制
- ✅ **AOP自动验证** - 无需手动编写验证代码

## 📋 实施清单

### 1. 核心组件

**已创建的组件：**

- `@FileSizeLimit` - 文件大小限制注解
- `FileSizeLimitUtils` - 文件大小验证工具类
- `FileSizeLimitAspect` - AOP切面自动验证
- 扩展的`SysOssController` - 多种上传接口示例

### 2. 使用方法

#### 方法一：注解式配置（推荐）

```java
@PostMapping("/upload")
@FileSizeLimit(maxSizeMB = 50, message = "文件最大支持50MB")
public R<SysOssUploadVo> upload(@RequestPart("file") MultipartFile file) {
    // 业务逻辑，文件大小会自动验证
}
```

#### 方法二：手动验证

```java
@PostMapping("/upload")
public R<SysOssUploadVo> upload(@RequestPart("file") MultipartFile file) {
    // 手动验证文件大小
    String validation = FileSizeLimitUtils.validateFileSize(file, 50 * 1024 * 1024L);
    if (validation != null) {
        return R.fail(validation);
    }
    // 业务逻辑
}
```

#### 方法三：智能验证

```java
@PostMapping("/upload")
public R<SysOssUploadVo> upload(@RequestPart("file") MultipartFile file) {
    // 根据文件类型自动选择大小限制
    String validation = FileSizeLimitUtils.validateFileSizeSmartly(file);
    if (validation != null) {
        return R.fail(validation);
    }
    // 业务逻辑
}
```

## 🔧 注解参数详解

### @FileSizeLimit 注解属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `maxSize` | long | 50MB | 最大文件大小（字节） |
| `maxSizeMB` | long | -1 | 最大文件大小（MB），优先级高于maxSize |
| `allowedTypes` | String[] | {} | 支持的文件类型（暂未实现） |
| `message` | String | "文件大小超出限制" | 自定义错误消息 |
| `enabled` | boolean | true | 是否启用验证 |

### 使用示例

```java
// 基本用法
@FileSizeLimit(maxSizeMB = 100)

// 自定义错误消息
@FileSizeLimit(maxSizeMB = 10, message = "头像文件不能超过10MB")

// 禁用验证（用于特殊情况）
@FileSizeLimit(enabled = false)

// 字节级精确控制
@FileSizeLimit(maxSize = 5 * 1024 * 1024L) // 5MB
```

## ⚙️ 配置说明

### 1. 全局配置（application.yml）

```yaml
spring:
  servlet:
    multipart:
      # 全局最大文件大小（作为兜底限制）
      max-file-size: 500MB
      # 全局最大请求大小
      max-request-size: 600MB
```

### 2. 自定义默认大小限制

修改 `FileSizeLimitUtils` 中的常量：

```java
public class FileSizeLimitUtils {
    // 自定义各类型文件的默认大小限制
    public static final long IMAGE_MAX_SIZE = 20 * 1024 * 1024L; // 改为20MB
    public static final long VIDEO_MAX_SIZE = 1024 * 1024 * 1024L; // 改为1GB
    // ...
}
```

## 🔧 故障排除

### 1. AOP切面不生效

确保在启动类上开启AOP：

```java
@SpringBootApplication
@EnableAspectJAutoProxy
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### 2. 注解不起作用

检查FileSizeLimitAspect是否被Spring扫描到：

```java
@Component  // 确保有这个注解
@Aspect
public class FileSizeLimitAspect {
    // ...
}
```

### 3. 全局限制仍然生效

Spring Boot的全局限制优先级最高，如果需要更大的文件，需要同时调整：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 1GB  # 必须大于等于所有接口的最大限制
```
