# 若依AI视频播放功能实施指南

## 🎯 功能概述

本实施方案为若依AI系统添加了完整的视频播放功能，采用轻量级架构设计，具有成本低、实施简单、维护方便的特点。

### 核心特性

- ✅ **HTML5原生播放器** - 无需第三方播放器库
- ✅ **多格式支持** - 支持MP4、AVI、WEBM、MOV等15+种视频格式  
- ✅ **OSS存储集成** - 复用现有对象存储服务
- ✅ **权限控制** - 完整的角色权限管理
- ✅ **播放统计** - 播放次数统计和热门视频排行
- ✅ **分类管理** - 视频分类和标签系统
- ✅ **文件验证** - 安全的文件类型和大小验证

### 3. API接口

#### 视频上传接口
```http
POST /resource/oss/upload/video
Content-Type: multipart/form-data

参数：
- file: 视频文件 (required)
- title: 视频标题 (optional)
- description: 视频描述 (optional)
- category: 视频分类 (optional)
- tags: 视频标签 (optional)
- isPublic: 是否公开 (optional, default: "1")
```

#### 视频管理接口
```http
# 获取视频列表
GET /system/video/list

# 获取视频详情
GET /system/video/{videoId}

# 获取播放URL
GET /system/video/play/{videoId}

# 获取公开视频列表（无需权限）
GET /system/video/public/list?category=教育&keyword=搜索词

# 获取热门视频（无需权限）
GET /system/video/public/hot?limit=10
```

### 4. 权限配置

系统已自动创建以下权限：

- `system:video:list` - 视频列表查看
- `system:video:query` - 视频详情查看
- `system:video:add` - 视频信息添加
- `system:video:edit` - 视频信息编辑
- `system:video:remove` - 视频删除
- `system:oss:upload:video` - 视频文件上传

## 🎨 前端集成示例

### HTML5播放器基础用法

```html
<video controls width="800" height="450">
    <source src="{videoUrl}" type="video/mp4">
    您的浏览器不支持视频播放
</video>
```

### JavaScript API调用示例

```javascript
// 上传视频
async function uploadVideo(file, title, description) {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('title', title);
    formData.append('description', description);
    
    const response = await fetch('/resource/oss/upload/video', {
        method: 'POST',
        body: formData
    });
    
    return await response.json();
}

// 获取视频播放URL
async function getPlayUrl(videoId) {
    const response = await fetch(`/system/video/play/${videoId}`);
    const result = await response.json();
    return result.data; // 返回播放URL
}

// 播放视频
function playVideo(videoId) {
    getPlayUrl(videoId).then(url => {
        const video = document.getElementById('player');
        video.src = url;
        video.play();
    });
}
```

## 📊 成本分析

### 资源消耗

- **存储成本**：使用现有OSS服务，按实际使用量计费
- **带宽成本**：视频流量成本，建议配置CDN加速
- **服务器资源**：几乎无额外消耗，复用现有Spring Boot应用

### 节约措施

1. **智能缓存**：热门视频优先缓存
2. **格式优化**：推荐使用H.264编码的MP4格式
3. **分辨率控制**：建议上传1080P以下视频
4. **自动清理**：定期清理低播放量视频

## 🔍 故障排查

### 常见问题

**1. 视频上传失败**
- 检查文件大小是否超限
- 验证文件格式是否支持
- 确认OSS配置是否正确

**2. 视频无法播放**
- 检查浏览器是否支持视频格式
- 验证OSS文件访问权限
- 确认视频文件是否损坏

**3. 权限不足**
- 检查用户角色权限配置
- 验证菜单权限是否正确分配
