# 多角色权限验证指南

## 📋 问题背景

在智图工厂的权限测试中发现，`admin`用户实际上具有**两个角色**：
- `superadmin`（超级管理员）
- `admin`（普通管理员）

这导致原有测试脚本对admin权限的判断出现**大量误判**。

## 🔧 问题解决方案

### 智能权限期望计算
```powershell
# 新测试脚本的权限计算逻辑
function Get-ExpectedPermission {
    param([string]$UserType, [array]$RequiredRoles)
    
    $roleInfo = $Global:UserRoleInfo[$UserType]
    
    # 🔑 关键改进：优先检查超级管理员
    if ($roleInfo.IsSuperAdmin -or $roleInfo.HasWildcardPermission) {
        return $true  # 超级管理员拥有所有权限
    }
    
    # 检查普通角色权限
    foreach ($requiredRole in $RequiredRoles) {
        if ($roleInfo.RoleKeys -contains $requiredRole) {
            return $true
        }
    }
    
    return $false
}
```
