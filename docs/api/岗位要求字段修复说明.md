# 岗位要求字段修复说明

## 问题描述
前端请求 `/designer/job/list` 时，无法像 mock 文件中一样获取到对应的 `requirements` 字段。

## 问题分析
1. **前端 mock 数据中存在 `requirements` 字段**：包含详细的岗位要求信息
2. **数据库表缺少字段**：`des_job_posting` 表中没有 `requirements` 字段
3. **后端实体类缺少字段**：`JobPosting` 实体类中没有对应的 `requirements` 属性

## 解决方案

### 1. 数据库层面修改

#### 1.1 更新表结构定义
- **文件**：`script/sql/designer_tables.sql`
- **修改**：在 `des_job_posting` 表定义中添加 `requirements` 字段
```sql
`requirements` TEXT COMMENT '岗位要求',
```

#### 1.2 创建字段添加脚本
- **文件**：`script/sql/update/add_requirements_field.sql`
- **功能**：为现有数据库表安全添加 `requirements` 字段
- **特点**：包含字段存在性检查，避免重复执行错误

### 2. 后端代码修改

#### 2.1 实体类更新
- **文件**：`ruoyi-modules/ruoyi-designer/src/main/java/org/ruoyi/designer/domain/JobPosting.java`
- **修改**：添加 `requirements` 字段及其注解
```java
/**
 * 岗位要求
 */
@Schema(description = "岗位要求", example = "本科及以上学历，设计相关专业，3年以上UI设计经验")
private String requirements;
```

### 3. 数据层面修改

#### 3.1 更新 mock 数据插入脚本
- **文件**：`script/sql/insert_mock_job_data.sql`
- **修改内容**：
  1. 在 INSERT 语句中添加 `requirements` 字段
  2. 为所有 6 个岗位添加对应的岗位要求数据
  3. 将原本混在 `description` 中的"职位要求"部分分离到 `requirements` 字段

## 修改后的数据结构

### 字段分离说明
- **`description`**：岗位描述（工作内容、职责等）
- **`requirements`**：岗位要求（学历、经验、技能要求等）

### 示例数据对比

**修改前**：
```sql
`description` = '负责腾讯游戏产品的交互设计工作...

职位要求：
本科及以上学历，设计相关专业...'
```

**修改后**：
```sql
`description` = '负责腾讯游戏产品的交互设计工作...',
`requirements` = '本科及以上学历，设计相关专业...'
```

## 影响范围

### 前端影响
- ✅ **正面影响**：前端现在可以正确获取到 `requirements` 字段
- ✅ **兼容性**：与 mock 数据格式完全一致

### 后端影响
- ✅ **API 响应**：`/designer/job/list` 和 `/designer/job/{id}` 接口现在返回 `requirements` 字段
- ✅ **数据完整性**：岗位描述和要求分离，数据结构更清晰
- ✅ **向后兼容**：现有功能不受影响

## 执行步骤

### 对于新环境
1. 使用更新后的 `script/sql/designer_tables.sql` 创建表结构

### 对于现有环境
1. 执行 `script/sql/update/add_requirements_field.sql` 添加字段
2. 执行 `script/sql/insert_mock_job_data.sql` 插入测试数据
3. 重新编译并部署后端代码

3. **前端验证**：确认前端可以正确显示岗位要求信息
