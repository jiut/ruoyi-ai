# 设计师模块逻辑删除实施指南

## 执行步骤

### 阶段1：数据库结构修改（紧急）

#### 1.1 备份数据库
```bash
# 备份当前数据库
mysqldump -u root -p ruoyi > ruoyi_backup_$(date +%Y%m%d_%H%M%S).sql

# 验证备份文件
ls -la ruoyi_backup_*.sql
```

#### 1.2 执行数据库修改脚本
```bash
# 进入项目目录
cd /path/to/ruoyi-ai

# 执行逻辑删除迁移脚本
mysql -u root -p ruoyi < script/sql/logical_delete_migration.sql
```

#### 1.3 验证数据库修改
执行脚本后，检查以下内容：

1. **外键约束验证**：所有 DELETE_RULE 应该是 'RESTRICT'
2. **字段验证**：所有核心表应该有 del_flag、del_time、del_by 字段
3. **索引验证**：所有 del_flag 字段应该有对应的索引
