# 设计师档案管理接口优化方案

## 📋 项目概述

基于用户档案自主管理需求，优化现有档案管理接口的权限控制，让设计师能够完整地管理自己的工作经历、教育背景、作品集和获奖记录，同时保持系统的安全性和权限控制。

## 🔧 接口设计架构（按场景分工）

基于**方案1：保持现有设计，明确场景分工**的原则，将档案管理接口分为三类：

### 接口分类设计

#### 1. 管理员接口 - 操作任意用户数据
- **使用场景**: 后台管理系统，管理员操作
- **权限级别**: 超级管理员权限
- **数据范围**: 可操作任意用户的数据

#### 2. 用户自助接口 - 操作自己的数据  
- **使用场景**: 前端用户界面，用户自主管理
- **权限级别**: 普通用户权限 + 身份验证
- **数据范围**: 只能操作自己的数据

#### 3. 档案查询接口 - 查询指定用户数据
- **使用场景**: 档案展示页面，查看他人档案
- **权限级别**: 公开访问（无需特殊权限）
- **数据范围**: 查询指定用户的公开数据

```java
 * 用户修改自己的工作经历
 */
@Log(title = "工作经历", businessType = BusinessType.UPDATE)
@PutMapping("/user/work-experience/{experienceId}")
public R<Void> editUserWorkExperience(
    @PathVariable Long experienceId,
    @Validated @RequestBody WorkExperience workExperience) {
    
    // 检查记录是否存在且属于当前用户
    WorkExperience existing = workExperienceService.selectWorkExperienceById(experienceId);
    if (existing == null) {
        return R.fail("工作经历不存在");
    }
    
    Long currentDesignerId = getCurrentDesignerId();
    if (!existing.getDesignerId().equals(currentDesignerId)) {
        return R.fail("无权限编辑此工作经历");
    }
    
    // 确保不能修改设计师ID和记录ID
    workExperience.setExperienceId(experienceId);
    workExperience.setDesignerId(currentDesignerId);
    
    return toAjax(workExperienceService.updateWorkExperience(workExperience));
}
```

```java
private Long getCurrentDesignerId() {
    List<UserBinding> bindings = userBindingService.getBindingsByUserId(LoginHelper.getUserId());
    return extractDesignerId(bindings);

/**
 * 从绑定信息中提取设计师ID
 */
private Long extractDesignerId(List<UserBinding> bindings) {
    return bindings.stream()
        .filter(binding -> "designer".equals(binding.getEntityType()) && "1".equals(binding.getBindingStatus()))
        .map(UserBinding::getEntityId)
        .findFirst()
        .orElse(null);
}

/**
 * 基本参数验证 - 设计师ID
 */
private boolean isValidDesignerId(Long designerId) {
    return designerId != null && designerId > 0;
}
```

### 1. 信息完整度计算接口

**文件**: `ruoyi-modules/ruoyi-designer/src/main/java/org/ruoyi/designer/controller/UserRegistrationController.java`

```java
/**
 * 获取用户档案完整度
 */
@Operation(
    summary = "获取档案完整度", 
    description = "计算当前用户各身份的档案完整度并提供改进建议"
)
@GetMapping("/profile/completeness")
public R<ProfileCompletenessVo> getProfileCompleteness() {
    Long userId = LoginHelper.getUserId();
    
    ProfileCompletenessVo completeness = new ProfileCompletenessVo();
    
    // 检查用户绑定的身份类型
    List<UserBinding> bindings = userBindingService.getBindingsByUserId(userId);
    
    for (UserBinding binding : bindings) {
        if (!"1".equals(binding.getBindingStatus())) continue; // 只处理有效绑定
        
        switch (binding.getEntityType()) {
            case "designer":
                DesignerCompletenessVo designerCompleteness = calculateDesignerCompleteness(binding.getEntityId());
                completeness.setDesigner(designerCompleteness);
                break;
            case "enterprise":
                EnterpriseCompletenessVo enterpriseCompleteness = calculateEnterpriseCompleteness(binding.getEntityId());
                completeness.setEnterprise(enterpriseCompleteness);
                break;
            case "school":
                SchoolCompletenessVo schoolCompleteness = calculateSchoolCompleteness(binding.getEntityId());
                completeness.setSchool(schoolCompleteness);
                break;
        }
    }
    
    return R.ok(completeness);
}

/**
 * 计算设计师档案完整度
 */
private DesignerCompletenessVo calculateDesignerCompleteness(Long designerId) {
    Designer designer = designerService.selectDesignerById(designerId);
    
    DesignerCompletenessVo completeness = new DesignerCompletenessVo();
    
    // 基础信息完整度 (权重40%)
    int basicScore = 0;
    if (StringUtils.isNotBlank(designer.getDesignerName())) basicScore += 20;
    if (StringUtils.isNotBlank(designer.getPhone())) basicScore += 20;
    if (StringUtils.isNotBlank(designer.getEmail())) basicScore += 20;
    if (StringUtils.isNotBlank(designer.getProfession())) basicScore += 20;
    if (StringUtils.isNotBlank(designer.getDescription())) basicScore += 20;
    completeness.setBasicInfo(basicScore);
    
    // 作品集完整度 (权重25%)
    List<Work> works = workService.selectWorkByDesignerId(designerId);
    int workScore = Math.min(works.size() * 10, 100);
    completeness.setPortfolio(workScore);
    
    // 工作经历完整度 (权重20%)
    List<WorkExperience> experiences = workExperienceService.selectWorkExperienceByDesignerId(designerId);
    int expScore = Math.min(experiences.size() * 25, 100);
    completeness.setExperience(expScore);
    
    // 教育背景完整度 (权重15%)
    List<Education> educations = educationService.selectEducationByDesignerId(designerId);
    int eduScore = Math.min(educations.size() * 50, 100);
    completeness.setEducation(eduScore);
    
    // 计算总体完整度
    int overall = (int) (basicScore * 0.4 + workScore * 0.25 + expScore * 0.2 + eduScore * 0.15);
    completeness.setOverall(overall);
    
    // 生成改进建议
    completeness.setSuggestions(generateImprovementSuggestions(completeness));
    
    return completeness;
}

/**
 * 生成改进建议
 */
private List<String> generateImprovementSuggestions(DesignerCompletenessVo completeness) {
    List<String> suggestions = new ArrayList<>();
    
    if (completeness.getBasicInfo() < 80) {
        suggestions.add("完善基础信息：建议补充个人简介、联系方式和职业技能");
    }
    
    if (completeness.getPortfolio() < 50) {
        suggestions.add("上传作品集：至少上传5个代表性作品以展示您的设计能力");
    }
    
    if (completeness.getExperience() < 50) {
        suggestions.add("添加工作经历：详细的工作经历有助于企业了解您的职业背景");
    }
    
    if (completeness.getEducation() < 50) {
        suggestions.add("补充教育背景：学历信息能够展示您的专业基础");
    }
    
    return suggestions;
}
```

```typescript
  static async deleteWorkExperience(experienceIds: number[]) {
    const response = await request.delete(`/designer/work-experience/${experienceIds.join(',')}`);
    return response;
  }
}
```

### 3. 通用身份信息提取工具函数

```typescript
interface UserIdentities {
  designerId: number | null;
  enterpriseId: number | null;
  schoolId: number | null;
}

/**
 * 从用户绑定信息中提取各种身份ID
 */
const extractUserIdentities = (bindings: UserBinding[]): UserIdentities => {
  const identities: UserIdentities = {
    designerId: null,
    enterpriseId: null,
    schoolId: null
  };
  
  bindings.forEach(binding => {
    if (binding.bindingStatus === '1') { // 1表示有效绑定
      switch (binding.entityType) {
        case 'designer':
          identities.designerId = binding.entityId;
          break;
        case 'enterprise':
          identities.enterpriseId = binding.entityId;
          break;
        case 'school':
          identities.schoolId = binding.entityId;
          break;
      }
    }
  });
  
  return identities;
};
```

## 📝 实施注意事项

### 1. 权限控制原则

- **超级管理员**：拥有所有档案信息的查看和编辑权限
- **设计师用户**：只能查看和编辑自己的档案信息
- **公开访问**：所有用户都可以查看设计师的档案信息（无需特殊权限）

### 2. 安全机制

- **身份验证**：所有接口都需要用户登录
- **权限校验**：通过 `DesignerPermissionUtils.hasDesignerPermission()` 验证
- **数据隔离**：防止用户修改他人的档案信息
- **参数安全**：防止恶意修改 designerId 等关键参数

### 3. 错误处理

- **参数验证**：严格验证输入参数的合法性
- **数据不存在**：优雅处理数据不存在的情况
- **系统异常**：返回明确的错误信息，不暴露系统内部信息

### 4. 性能考虑

- **分页查询**：list 接口支持分页，避免一次性加载过多数据
- **缓存策略**：可考虑对完整度计算结果进行缓存
- **数据库优化**：确保相关查询有适当的索引
