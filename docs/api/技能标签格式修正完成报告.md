## 🚀 使用指南

### 开发者使用
1. **前端开发**: 使用英文简写格式存储和传输，通过 `SkillTagUtils.getTagDisplayName()` 转换为中文显示
2. **后端开发**: API统一返回英文简写格式，前端负责本地化显示
3. **数据库操作**: 所有技能标签字段使用英文简写格式存储

### 数据迁移步骤
1. 备份现有数据库
2. 执行 `script/sql/update/update_skill_tags_format.sql` 脚本
3. 验证转换结果
4. 重启应用服务
